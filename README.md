# متجر مستر فون

صفحة تطبيقات للبوكسات والتلفزيونات: https://mustafaasaad85.github.io/store/

## إضافة تطبيق
1. ارفع ملف الـ APK على الإصدار **apps** (Releases → apps → Edit → Attach files).
2. أضف سطر للتطبيق بملف `data.json`، وخلي `file` نفس اسم الملف اللي رفعته.

## تحديث تطبيق
1. بالإصدار **apps** احذف الملف القديم وارفع الجديد **بنفس الاسم**.
2. غيّر رقم `version` بملف `data.json`.

الرابط يبقى نفسه، فالزبائن ما يحتاجون شي جديد.
